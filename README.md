### Designing Networks. Connecting Systems. Solving Real-World Problems.

Welcome to my Network Engineering Portfolio!

## 🚀 What You'll Find Here

This portfolio showcases practical projects and technical labs covering:

- **Network Design & Architecture** – Designing scalable and structured network environments.
- **Routing & Switching** – Configuring Cisco routers, switches, and routing protocols.
- **VLANs & Network Segmentation** – Building secure, segmented departmental networks.
- **IP Addressing & Subnetting** – Planning and implementing structured IP addressing schemes.
- **Network Services** – Working with DHCP, DNS, NAT, and other essential network services.
- **Network Security** – Implementing access control, segmentation, and network security practices.
- **Troubleshooting** – Diagnosing connectivity issues and resolving network-related problems.
